This project is a guided ETL (Extract, Transform, Load) pipeline designed to demonstrate modern data engineering practices. It orchestrates complex data workflows by integrating three key industry-standard tools:

* **Airflow:** Manages the workflow orchestration, scheduling, and task monitoring.
* **dbt (data build tool):** Handles data transformation logic directly within the warehouse, ensuring modularity and data quality.
* **Snowflake:** Serves as the cloud-native data warehouse for scalable storage and compute.

This pipeline serves as a practical implementation of a robust data engineering architecture, showcasing how to effectively move, transform, and manage data from source to destination.
